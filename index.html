ℹ️ 地図データ（GeoJSON）の体裁・推奨仕様について

本ジェネレータは標準的な GeoJSON (RFC 7946) に準拠しています。以下の仕様のファイルをご用意いただくことで、任意の選挙区地図を正確に読み込み可能です。

  • ルート形式: FeatureCollection であること。
  • ジオメトリ: Polygon または MultiPolygon（島嶼部や飛び地を含む区にも完全対応）。
  • 座標系:
    • 世界測地系・経緯度（WGS84 / EPSG:4326、例: [133.9, 34.6]）推奨。
    • またはピクセル平面直角座標（D3.geoIdentityにより自動センタリング・フィットされます）。
  • 推奨属性（properties）:
    • id または code: 選挙区の一意な識別コード（例: "OK-1", 1301 など）
    • name: 選挙区の正式名称（例: "岡山1区", "東京1区" など）

Election Map Studio — クイックスタートガイド

初めてご利用の方へ：基本操作と機能の案内

📌 本ツールについて

本ツールは、各種選挙制度（小選挙区制、中選挙区制、小選挙区比例代表並立制など）に基づき、 選挙結果をWikipediaに掲載されるような完成された一枚の地図（SVG/PNG形式）として作成・集計・ダウンロードできるWebアプリケーションです。

🚀 基本的な使い方（5つのステップ）

1 制度の選択

「01 制度」タブで、小選挙区比例代表並立制（衆議院モデル）などのプリセットを選択します。独自のGeoJSON地図の読み込みも可能です。

2 政党の設定

「02 政党」タブで、参加する政党の追加・削除、正式名・略称、表示カラーピッカーを調整します。

3 選挙区結果の入力

「03 選挙区」タブまたは地図クリックで、各区の定数・候補者・得票数を設定。得票数を入力すると自動で当落・得票率グラデーションが計算されます。

4 比例区の設定

「04 比例区」タブで、地図外の比例代表ブロックを任意に追加。定数・配分方式（ドント式等）・票数を入力すると議席ボールが自動配置されます。

5 地図出力・保存

ヘッダーの「SVG出力」ボタンでWikipedia規格の自己完結SVGをダウンロード。「保存」でプロジェクト全体のバックアップが可能です。

💡 知っておくと便利な機能

  • 機動的な集計モード切替： 各選挙区および全体で「得票数入力（自動）」と「順位指定（手動）」をワンタッチで切り替えられます。まずは順位だけパパッと指定して地図を作り、後から得票数で精緻化できます。
  • 地図クリックでクイック編集： 地図上の選挙区をクリックすると、左下の「クイックインスペクター」からその場で定数変更・得票数入力・順位入れ替えが可能です。
  • 候補者の一括追加補助： 「03 選挙区」タブ上部のツールバーから、全選挙区に特定党派の候補者をワンクリックで一括追加・削除できます。
  • 折り畳み表示： 選挙区数が多い場合、「折り畳む」ボタンを押すとコンパクトになり、作業したい区だけを開いて閲覧・編集できます。
  • 過半数積み上げバー： 地図上部に各党の総議席と過半数（Majority Line）の達成状況を示すWikipediaスタイルのバーが表示されます。
  • ショートカット： Ctrl + Z（元に戻す）、Ctrl + Y（やり直す）、Ctrl + S（プロジェクト保存）に対応しています。

⚖️ 比例配分方式ミニ解説

ドント式 (D'Hondt): 得票数を 1, 2, 3... で割り、大きい順に議席を割り当てます（日本の衆院比例などで標準）。
サン＝ラグ式 (Sainte-Laguë): 得票数を 1, 3, 5... で割り、大政党への偏りを抑えた中立的配分を行います。
最大剰余式 (Hare / Droop): 議席クオータで割った商を基本議席とし、残余議席を余剰得票の大きい順に配分します。
