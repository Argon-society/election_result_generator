# Election Map Studio — Wikipedia Style Result Generator

ブラウザ上で動作する、Wikipediaスタイルの完成度の高い選挙結果地図（SVG/PNG）を作成・集計・書き出しできるジェネレータサイトです。GitHub Pagesに対応した完全なクライアントサイド静的Webアプリケーションです。

---

## 主な特徴・機能

### 1. 多様な選挙制度のモデル化
- **小選挙区比例代表並立制（衆議院モデル）**
  - 地図上の各選挙区（1人区）＋ 地図外に任意個数作成できる比例代表ブロック（中国ブロック、東京ブロックなど）。
- **単純小選挙区制（FPTP）**
  - 全面1人区、最多得票者が当選。比例区なし。
- **大選挙区・中選挙区制（SNTV 単記非移譲式）**
  - 全面3〜6人区などの複数人区。得票上位から定数分が当選。
- **大選挙区比例代表並立制**
  - 複数人区の選挙区 ＋ 比例代表ブロック。
- **純粋比例代表制**
  - 地域選挙区を持たず、比例区のみで集計・議席配分。
- **カスタム選挙制度**
  - 選挙区ごとに定数を自由設定、比例区も任意個数作成可能。
  - カスタム制度定義のみを `.emsys.json` 形式で保存・読込して再利用可能。

### 2. 比例代表配分アルゴリズム
- **ドント式 (D'Hondt)**：除数列 1, 2, 3, ... による標準的除数方式
- **サン＝ラグ式 (Sainte-Laguë)**：除数列 1, 3, 5, ... による中立的除数方式
- **最大剰余式 (Largest Remainder)**
  - **Hare基数 (Hare Quota)**
  - **Droop基数 (Droop Quota)**
- 比例区ごとに「得票数入力（自動得票率算出＆配分）」と「得票率(%)直接入力（自動配分）」の双方に対応。

### 3. Wikipediaスタイルの視覚表現
- **得票率シェーディング（濃淡表現）**
  - 選挙区領域の色分けは、当該区内の最大得票党派（複数人区においては党派ごとの合算得票数で比較）の党派色をベースに、得票率（40%未満、40-50%、50-60%、60%以上など）に応じたWikipedia標準の段階的濃淡で表現。
- **定数分の〇オブジェクト（議席ボール）**
  - 各選挙区内に定数分の丸オブジェクトを配置。当選順位（1位、2位、3位…）順に当選党派の色を適用。
- **地図外の比例代表ブロック**
  - 地図の右サイドパネル（または下部パネル）に各比例区のカードを配置し、各党の獲得議席数分の〇オブジェクトを整然と描画。
- **Wikipedia風凡例パネル**
  - 小選挙区・比例代表・合計獲得議席数のサマリー表および得票率シェーディング階調ガイドをSVG内に統合。

### 4. 操作性とデータ連携
- **硬派で使いやすいタブUI**
  - 「制度」「政党」「選挙区」「比例区」「表示」「検証」の6タブで快適に操作。
  - 地図上の選挙区をクリックすると即座に対応する入力カードへ連動スクロール。
- **Undo / Redo**（Ctrl+Z / Ctrl+Y）完全対応
- **完全自己完結型SVGエクスポート**
  - CSSスタイルやフォント定義が埋め込まれており、WikipediaコモンズやInkscape、Illustrator等でそのまま利用可能。
- **プロジェクト保存・読込**（`.emproj.json`）
  - 作業中の地図データ、選挙区結果、比例区設定、配色を丸ごと保存・復元。

## ローカルでの実行

外部JSON（GeoJSON / 政党データ）を読み込むため、HTTPサーバー経由で開くことを推奨します。

```bash
# Python 3
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。

---

## GitHub Pagesへのデプロイ

1. リポジトリのルートに `index.html`, `app.js`, `style.css`, `data/` が配置されていることを確認します。
2. GitHubリポジトリの **Settings** → **Pages** を開きます。
3. **Build and deployment** の Source で **Deploy from a branch** を選択します。
4. Branch を **main**（または master）、Folder を **/(root)** に設定して **Save** をクリックします。
5. 数分で公開URL（`https://<username>.github.io/<repo>/`）にて公開されます。
