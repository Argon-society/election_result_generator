# Election Map Studio v4 Professional

硬派な選挙資料作成を目的とした、ブラウザベースの選挙結果地図ツールです。

## v4の主な変更

- AIサービス風のカードUI・大きな装飾・過剰なコピーを廃止
- 選挙資料・統計ツールに近い密度と操作感へUIを再設計
- 「制度プリセット」と「集計エンジン」を分離
- 衆議院小選挙区
- 衆議院比例代表（ブロック）
- 参議院選挙区
- 参議院比例代表（全国）
- 大選挙区・単記非移譲式
- 複数人区・党派順位方式
- カスタム制度
- 得票数入力 / 設定順位入力
- 複数人区で候補者単位の得票数を入力可能
- 当選ボールは「議席数分」を必ず生成
- 得票数モードでは得票順
- 設定順位モードでは1位→2位→…の設定順
- ボールの色は当選候補・党派の党派色
- 比例代表はドント式 / サン＝ラグ式
- プロジェクトJSON保存・読込
- Undo / Redo
- GeoJSONのID重複・空IDを検証
- SVG / PNG書き出し
- SVGは固定viewBoxを用いて、ブラウザ上の表示と書出しの座標系を統一
- 保存ファイル・SVGにツールのバージョン情報を記録

## 日本の制度について

本ツールは「実選挙結果を地図化するための汎用器」であり、入力したGeoJSONの単位を尊重します。

衆議院は小選挙区と比例代表（地域ブロック）を組み合わせる並立制です。比例代表の議席配分にはドント式を用います。
参議院は選挙区選挙と比例代表選挙があり、比例代表は全国を一つの選挙区とする方式です。参議院比例では特定枠等、候補者順位に関する固有のルールがあります。

本版では、地図上の「議席ボール」を実選挙の当選枠に対応させることを重視し、制度固有の最終当選者決定ロジックは段階的に拡張できる構造にしています。

## 注意

data/okayama-sample.geojson はUI確認用の簡略図であり、実際の岡山県選挙区境界ではありません。
実選挙の地図化では、公式・信頼できる境界データと選挙結果を別途用意してください。

比例代表についても、現在はGeoJSON Featureごとを比例集計単位として扱う汎用モデルです。
衆院11ブロックを自動判定する機能や、実際の参院比例の候補者票・特定枠・当選者決定順を完全再現する処理は、実データ仕様に合わせて追加する拡張領域です。

## GitHub Pages

リポジトリのルートに `index.html` がある状態で、GitHub Pagesの
Settings → Pages → Deploy from a branch → main → /(root)
を選択してください。

## ローカル

外部JSONをfetchするため、ダブルクリックではなく簡易HTTPサーバーを推奨します。

```bash
python -m http.server 8000
```

その後 `http://localhost:8000/` を開きます。
