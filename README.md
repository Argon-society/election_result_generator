# Election Map Studio — Wikipedia Style Result Generator
**v5.1 Professional**

ブラウザ上で動作する、Wikipediaスタイルの完成度の高い選挙結果地図（SVG/PNG）を作成・集計・書き出しできるプロフェッショナルなジェネレータサイトです。GitHub Pagesに対応した完全なクライアントサイド静的Webアプリケーションです。

---

## 核心的な機能と最新アップデート

### 1. 「選挙区」と「比例区」の完全分離と並立システム
- **選挙区（Districts）**: 地図上のコンポーネント（ポリゴン）と1対1で対応。各選挙区ごとに**個別の議員定数（1〜20）**を完全個別に設定可能。一括定数変更ツールも備えつつ、区ごとの自由なカスタム定数を保証。
- **比例区（PR Blocks）**: 地図ジオメトリを持たない独立したブロックとして、**地図外に任意個数（0〜N個）**作成可能。各ブロックごとに独立した定数（例: 北海道8、東北12、東京19など）および配分方式（ドント式、サン＝ラグ式、最大剰余式Hare/Droop）を設定。
- **並立（Parallel System）**: 選挙区と比例区は常に並立可能。地図上には各選挙区のポリゴンと定数分の〇オブジェクト、地図外（右サイドパネル等）には各比例ブロックと獲得議席ボールが同時に一枚の地図（SVG）として美しく描画されます。
- **右サイドパネルの重複解消**: 議席数や比例ブロック数に応じて、議席ボールグリッドと政党別獲得議席サマリーの垂直オフセットを動的計算。ボールとテキストの重なりを完全に排除しました。

### 2. 候補者の順位・得票数・当落判定システム
- 各選挙区に、**「党派」と「順位」**の属性を持った候補者を配置。
- **得票数を設定した場合（任意）**:
  - 候補者の得票数順で**順位が自動決定**され、上位定数分が当選。
  - 選挙区コンポーネントの色は**最大得票党派（複数人区は党派合算）の得票率に応じた美しいグラデーション**で表示。
- **得票数を設定しない場合（空欄）**:
  - ユーザーが指定した**手動順位（1位、2位、3位…）**をそのまま尊重（▲/▼ボタンで直感的に並べ替え可能）。
  - 選挙区コンポーネントの色は**第1位当選候補の党派本色（鮮明な不透明カラー、白抜けゼロ）**で表示。
- **特定党派候補の一括追加・補助ツール**:
  - 全選挙区に特定党派の候補者をワンクリックで一括追加・削除するツールや、主要政党候補の一括展開機能を搭載。

### 3. 設定画面の「折り畳み（アコーディオン）」表示
- 各選挙区カードはワンクリックで折り畳み／展開が可能。
- 折り畳み時でも「選挙区名」「定数」「現在の当選者党派バッジ」がヘッダーにコンパクトに表示され、多数の選挙区があっても快適に一覧できます。
- 上部に「すべて展開」「すべて折り畳む」ボタンを完備。
- 地図上の選挙区をクリックした際は、該当選挙区カードが自動的に展開・スクロール連動します。

### 4. 初心者向け「包括的ヘルプ・ガイド」モーダル
- ヘッダーの「❓ ヘルプ / 使い方」ボタンから、初心者向けの分かりやすいクイックスタートガイドをいつでも閲覧可能。
- 制度選択からSVG書き出しまでの5ステップ、便利機能（クイックインスペクター、一括追加ツール、ショートカットキー）、比例配分方式のミニ解説を収録。

### 5. 操作性の高い「クイックインスペクター」
- 地図上の選挙区をクリックすると、左下に「選択中選挙区クイックインスペクター」が表示。
- 右サイドパネルの比例区表示を遮ることなく、地図を見ながらその場で定数変更・候補者追加・順位入れ替え・得票数入力がリアルタイムに行えます。

### 6. 地図透明化問題の根本解消とグラデーション表現
- SVGのルートに不透明白背景（`#ffffff`）を確実に固定配置。
- 得票率グラデーション時でも最低濃度（50%以上）を保証し、淡色設定時でも白抜けして透明に見える不具合を解消。
- 得票数未設定時は純色（本色）、候補者なし時は不透明ライトグレー（`#d1d5db`）で描画。

### 7. エクスポートと保存
- **完全自己完結型SVGエクスポート**: インラインスタイルと不透明白背景を埋め込み、WikipediaコモンズやInkscape、Illustratorでそのまま美しく開ける単一SVGを出力。
- **高解像度PNGエクスポート**: 2倍スケールでラスタライズ保存。
- **プロジェクト保存・読込**（`.emproj.json`）：作業中の全データを保存・復元。
- **制度定義保存・読込**（`.emsys.json`）：作成した選挙制度（選挙区定数マップ・比例区構成）のみをテンプレートとして保存・再利用。

## ローカルでの実行

外部JSON（GeoJSON / 政党データ）を読み込むため、HTTPサーバー経由で開くことを推奨します。

```bash
# Python 3
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。

## GitHub Pagesへのデプロイ

1. リポジトリのルートに `index.html`, `app.js`, `style.css`, `data/` が配置されていることを確認します。
2. GitHubリポジトリの **Settings** → **Pages** を開きます。
3. **Build and deployment** の Source で **Deploy from a branch** を選択します。
4. Branch を **main**（または master）、Folder を **/(root)** に設定して **Save** をクリックします。
5. 数分で公開URL（`https://<username>.github.io/<repo>/`）にて公開されます。
