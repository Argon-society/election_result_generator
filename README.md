# Election Map Studio — Wikipedia Style Result Generator
**v5 Professional**

ブラウザ上で動作する、Wikipediaスタイルの完成度の高い選挙結果地図（SVG/PNG）を作成・集計・書き出しできるプロフェッショナルなジェネレータサイトです。GitHub Pagesに対応した完全なクライアントサイド静的Webアプリケーションです。

---

## 核心的な機能とアーキテクチャ

### 1. 「選挙区」と「比例区」の完全分離と並立システム
- **選挙区（Districts）**: 地図上のコンポーネント（ポリゴン）と1対1で対応。各選挙区ごとに**個別の議員定数（1〜20）**を自由設定可能。
- **比例区（PR Blocks）**: 地図ジオメトリを持たない独立したブロックとして、**地図外に任意個数（0〜N個）**作成可能。ブロックごとに個別の定数（例: 北海道8、東北12、東京19など）および配分方式を設定。
- **並立（Parallel System）**: 選挙区と比例区は常に並立可能であり、一枚の地図（SVG）上で「地図上の選挙区結果」と「地図外の比例代表ブロック結果」が統合表示されます。

### 2. 候補者の順位・得票数・当落判定システム
- 各選挙区に、**「党派」と「順位」**の属性を持った候補者を配置。
- **得票数を設定した場合（任意）**:
  - 候補者の得票数順で**順位が自動的に決定**され、上位定数分が当選。
  - 選挙区コンポーネントの色は**最大得票党派（複数人区は党派合算）の得票率に応じたグラデーション**で美しく表示。
- **得票数を設定しない場合（空欄）**:
  - ユーザーが指定した**手動順位（1位、2位、3位…）**をそのまま尊重（↑ / ↓ボタンで簡単に入れ替え可能）。
  - 選挙区コンポーネントの色は**第1位当選候補の党派本色（鮮明な不透明カラー、白抜けゼロ）**で表示。
- **特定党派候補の一括追加・補助ツール**:
  - 全選挙区に候補者を1人ずつ手作業で追加する手間を劇的に削減するため、**「全選挙区に特定党派の候補者をワンクリックで一括追加」**や「主要政党候補の一括展開」などの補助機能を搭載。

### 3. 地図透明化問題の根本解消とグラデーション表現
- SVGのルートに不透明白背景（`#ffffff`）を確実に固定配置。
- 得票率グラデーション時も最低明度・彩度（50%濃度以上）を担保し、淡色設定時でも白抜けして透明に見える不具合を完全に解消。
- 得票数未設定時は純色（本色）、候補者なし時は不透明ライトグレー（`#d1d5db`）で描画。

### 4. 安定したUI操作性とクイックインスペクター
- 地図上の選挙区をクリックした際、勝手にタブが切り替わったり画面がガタつく問題を解消。
- 地図右下に**「選択中選挙区クイックインスペクター」**が表示され、その場で定数の変更、候補者の追加・削除、順位の並べ替え（▲/▼）、得票数の入力が直感的に行えます。

### 5. 比例配分アルゴリズム
- **ドント式 (D'Hondt)**：標準的除数方式
- **サン＝ラグ式 (Sainte-Laguë)**：中立的除数方式
- **最大剰余式 (Hare基数 / Droop基数)**
- 各比例区で「得票数入力（得票率自動算出）」と「得票率(%)直接入力」を選択可能。

### 6. エクスポートと保存
- **完全自己完結型SVGエクスポート**: インラインスタイルと不透明白背景を埋め込み、WikipediaコモンズやInkscape、Illustratorでそのまま美しく開ける単一SVGを出力。
- **高解像度PNGエクスポート**: 2倍スケールでラスタライズ保存。
- **プロジェクト保存・読込**（`.emproj.json`）：作業中の全データを保存・復元。
- **制度定義保存・読込**（`.emsys.json`）：作成した選挙制度（選挙区定数マップ・比例区構成）のみをテンプレートとして保存・再利用。

## ローカルでの実行

外部JSON（GeoJSON / 政党データ）を読み込むため、HTTPサーバー経由で開くことを推奨します。

```bash
# Python 3
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。

---

## GitHub Pagesへのデプロイ

1. リポジトリのルートに `index.html`, `app.js`, `style.css`, `data/` が配置されていることを確認します。
2. GitHubリポジトリの **Settings** → **Pages** を開きます。
3. **Build and deployment** の Source で **Deploy from a branch** を選択します。
4. Branch を **main**（または master）、Folder を **/(root)** に設定して **Save** をクリックします。
5. 数分で公開URL（`https://<username>.github.io/<repo>/`）にて公開されます。
